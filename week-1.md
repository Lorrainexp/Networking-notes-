### Key Takeaways
* **Bullet 1:** [OSI is a 7 layer model that provides the standard for computers communication with each other. TCP/IP models are a 4 layer model for practical use]
* **Bullet 2:** [IP addresses identify devices on a network and come in 2 versions IPv4 and the more recent one IPv6. ]
* **Bullet 3:** [Ports (0 to 65535) act as virtual doors on a device to direct network traffic to the correct software application. ]
* **Bullet 4:** [A practical example of a port number would be port 443 which is used for HTTPS]
* **Bullet 4:** ['ping' is used to test connectivity, 'traceroute'is used to map the path to a destination, 'dig' quires DNS servers to find IP information
* **Bullet 5:** [To understand how computers communicate with each other, it is important for footprints and location]
